雪国 第三章 · 徒劳

夜色从窗棂上慢慢退下去，屋子里只剩下台灯的一小圈光。她把书翻到折角的那一页，指尖在纸面上停了停，像是在确认那些字还留在原来的地方。

远处的钟敲了两下。她想起下午在旧书店里看到的那本旧书，书脊已经磨白了，扉页上有一行褪色的钢笔字：赠给愿意慢下来的人。她当时没有买，走到街角又折了回来。

书店的老板正低头给一本书包皮，头也不抬地说：“那本啊，放了三年了。”她把钱放在柜台上，玻璃板下面压着泛黄的照片，边角翘起来，像一片干枯的叶子。

现在那本书就摊在膝头。纸有点脆，翻页的时候会发出很轻的响声，像有人在很远的地方说话，说到一半又停住了。
