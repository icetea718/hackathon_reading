# 界面原型（UI Prototype）

这是阅读器的**界面设计稿**：一个可以直接点击操作的 HTML 原型，用来确认视觉方向与交互，**不是应用本身**。

应用本体是 Flutter（`lib/`），实际界面在后续迭代里按这份设计稿实现。

## 怎么打开

直接双击 `index.html` 即可；或在当前目录起一个本地服务（避免个别浏览器的本地文件限制）：

```bash
python server.py          # http://127.0.0.1:8787
```

> `server.py` 对找不到的路径会回落到 `index.html`，随手贴错 URL 也不会 404。

## 里面有什么

| 区域 | 说明 |
| --- | --- |
| 书架 | 继续阅读大卡（封面 / 进度 / 摘要）、分类胶囊、封面网格（书脊高光、纸纹、悬停抬升） |
| 阅读页 | 顶部工具条、左侧竖排工具、衬线正文 + 首字下沉、底部章节进度 |
| 外观面板 | 风格切换、壁纸选择、自定义导入、模糊/压暗/通透度 |

**入口**：书架右上角「外观」按钮、阅读页顶栏的设置图标，打开的是同一个面板。
原型左下角还有一个灰色「原型」胶囊，用来在书架 / 阅读页之间切换（仅设计稿有，应用里不会有）。

## 两套风格

都要保留，由用户在「外观」面板里自选，不做二选一：

- **玻璃拟态（glass）**：毛玻璃卡片、更强的层次和浮起感，适合深色/花哨壁纸。
- **纸感书卷（paper）**：米白纸面、细边框、安静好读，适合浅色壁纸与长时间阅读。

风格会跟随壁纸自动切浅色/深色文字（浅色壁纸 → 白玻璃 + 深色字），不需要用户手动切主题。

## 壁纸

- **8 张内置**：极光夜空、晨雾山间、墨色书斋、暖阳琥珀、青竹雨林、海盐蓝调、雪原清晨、旧纸纹理。全部由渐变 + 噪点生成，不依赖第三方图片，无版权与体积负担。
- **自定义**：导入本地图片，自动缩放并采样亮度来决定浅色/深色文字。
- **三个调节**：模糊、压暗、面板通透度。

## URL 参数（写文档 / 截图用）

```
?screen=library|reader     切页面
?variant=glass|paper       切风格
?wallpaper=<预设 id>       指定壁纸
?drawer=1                  打开外观面板
?clean=1                   隐藏原型工具条
```

## 落到 Flutter 的约定

外观状态全部写进现有的 `settings` 表（不改表结构）：

```
appearance.style          glass | paper
appearance.wallpaper      预设 id，或 custom
appearance.wallpaperPath  自定义图片的本地路径
appearance.blur           0..24
appearance.dim            0..70
appearance.panelOpacity   20..95
```

- 内置壁纸用代码绘制（渐变 + 噪点 `CustomPainter`），不打包图片资源；
- 自定义图片用 `file_picker` 导入，复制到应用支持目录后存路径；
- 主题按壁纸亮度自动选浅/深，复用 `AppTheme` 并新增 paper 配色；
- 壁纸层做成共用 widget，书架与阅读页复用。
