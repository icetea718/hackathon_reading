# 双页阅读设计

日期：2026-11-04
状态：已确认（2026-11-04）

## 背景与意图

用户试读分页阅读后提出两件事：

1. Windows 桌面端的阅读页仍会出现滚动条，要求 TXT/EPUB 正文不能滚动、阅读器不再显示滚动条。
2. 希望像实体书一样左右并排两页，并且让用户自己选择单页还是双页；继续参考 NeatReader。

第 1 点已实现并提交（`37cf0f7`）：阅读器与 PDF 页整屏关闭桌面自动滚动条，正文 `SelectableText` 使用 `NeverScrollableScrollPhysics`。本文档只覆盖第 2 点与剩余核对。

## 目标

- 阅读设置新增「单页 / 双页」选项，**默认双页**（用户指定），选择持久化，下次打开沿用。
- 双页模式覆盖 TXT/EPUB 与漫画 EPUB。PDF 用户明确要求保持现状：单页、可滚动缩放、无滚动条，不做双页。
- TXT/EPUB 双页按章节内配对：每章从新的展开页左侧开始；章节页数为奇数时右侧留白；不跨章节拼接（用户选择方案 A）。
- TXT/EPUB 一次翻页前进/后退两页；点击区、方向键、PageUp/PageDown、底部按钮语义一致。
- 书签、标注、目录、进度续读在双页下仍落在正确的展开页。
- 窗口过窄时自动退回单页显示，但保存的偏好仍是用户选择的双页。
- 正文字面保持不可滚动；整个阅读器不出现桌面自动滚动条。

## 非目标

- 跨章节拼接（章节末页 + 下一章首页并排）。
- 右到左 / 竖排排版。
- 每本书单独覆盖全局的单页/双页设置。
- 双页下跨书缝选择文字（每页独立选择）。
- 目录、书签等抽屉去除滚动能力（它们保持可滚动，只是不显示自动滚动条）。
- PDF 双页。

## 已定决策

### 设置

- 设置键 `reader.spread`，取值 `single` / `double`，**默认 `double`**；读取到非法值回退 `double`。
- `ReaderSettingsSheet` 增加「排版」分段按钮（单页 / 双页），与字号、行距、背景一起通过 `onChanged` 回调，并在 `_saveSettings` 中写入。
- TXT/EPUB 从阅读设置进入；漫画没有字号设置，因此在顶部栏加一个「单页 / 双页」切换图标（tooltip 显示当前模式），点击即写入同一设置。PDF 不参与双页。

### 窗口阈值

- 可用宽度 < 880 逻辑像素时按单页渲染；阈值是显示策略，不修改已保存的设置。
- TXT/EPUB 在 `LayoutBuilder` 里按正文可用宽度判断；漫画在分页视图外用 `MediaQuery` 屏幕宽度判断（漫画的 `PageView` 需要先创建控制器）。

### TXT/EPUB

- 单页排版宽度：`clamp(maxWidth, 720) - 40`（现状）。
- 双页内容盒最大宽度 1320；内部分两栏，中间书缝 24；每栏左右内边距各 20。
  单栏文本宽度 = `(min(maxWidth, 1320) - 24) / 2 - 40`。
- 分页按单栏文本宽度重新计算；`PageLayout` 与全书页码签名必须包含双页标记，避免复用单页的页数缓存。
- 展开页 s 显示本章第 `2s`、`2s+1` 页；`2s+1` 不存在时右侧渲染空白栏。
- `_pageIndex` 在双页下始终归一到展开页左侧（`page - page % 2`）：
  - 进入双页时向下取整。
  - 下一页/上一页按 2 页移动；跨章仍沿用现有章节逻辑。
  - 章节第一页位于左侧；最后展开页可能右侧为空。
  - 页首/页尾禁用判断按展开页位置计算。
- 页脚：`第 a–b / n 页 · 全书 X / Y 页`；只有单页时 `第 a / n 页`。X 是展开页左侧页的全书页码（`bookPageAt`），Y 仍是全书**页**数（现有后台统计的页数之和，不换算成展开页数），未就绪显示 `…`。这样进度百分比与单页模式一致。
- 书签/标注/目录跳转：先按字符偏移求出目标页，再归一到展开页左侧；高亮与笔记仍按全文字符偏移存储。
- 进度：保存当前展开页左侧页的起始偏移；重新打开时由偏移求页并归一，落在包含锚点的展开页。改字号/行距/窗口后同样处理 `_pendingOffset`。
- 两个页面各自一个 `SelectableText.rich`，各自弹选择菜单；不能跨书缝选择。
- 视觉：两栏之间画一条淡竖线/浅阴影作为书缝；页面背景沿用现有配色。

### 漫画 EPUB

- 双页时 `PageView` 的每一“页”是一个展开页：显示第 `2i`、`2i+1` 张图并排（缺失则空白）；`itemCount = ceil(total / 2)`。
- 翻页、左右方向键、PageUp/PageDown、底部按钮都按展开页移动；漫画不加点击翻页区，避免与图片区域冲突。
- 当前页以展开页左侧页为准：标题、进度条、进度保存（`anchor.page` 存左侧页的 1-based 页码）；恢复进度时按 `floor(page/2)` 打开对应展开页。
- 书签按页存储：当前展开页左侧页的书签状态决定书架图标；跳到第 p 页则打开 `floor(p/2)` 展开页；书签栏仍显示具体页码。
- 目录抽屉页码不变，点击后打开包含该页的展开页。
- 窗口窄于阈值时退回单页。

### PDF（保持现状）

- 单页纵向滚动，pdfrx 自带缩放/拖动保留，不接管方向键。
- 页码栏、书签、目录、进度保存语义不变。
- 阅读页外层 `ScrollConfiguration(scrollbars: false)` 保持，PDF 页面不显示桌面自动滚动条。
- 不做双页设置入口，不读取 `reader.spread`。

## 验收标准

- 设置中切到双页后，TXT/EPUB 左右并排两页，中间有书缝；一次翻页走两页。
- 每章第一页在左侧；奇数页章节最后一页右侧留白，不出现下一章内容。
- 页脚、进度、书签、标注、目录跳转都落在包含目标的展开页。
- 漫画双页并排两张图，最后一页单独；进度与书签仍以具体页码为准。
- PDF 与现在完全一致：单页滚动、可缩放、无滚动条。
- 窄窗口自动单页；重新拉宽恢复双页。
- 阅读器无可见滚动条，正文不可滚动。
- `flutter analyze` 无问题，`flutter test` 全绿。

## 风险

- 双页分页宽度变化会让全书页码统计重新计算，首次切换需要等待页脚 `…` 变为数字。
- 双页下 `_pageIndex` 归一逻辑要与书签/标注跳转、重排保位置共用同一套换算，避免两处语义不一致。
- 漫画 `PageView` 从按页改成按展开页后，进度恢复与书签跳转的页↔展开页换算必须只有一处。

## 留给实现者的判断

- 书缝的具体视觉（竖线还是阴影）与间距。
- 展开页翻页是否需要动画（当前文本翻页无动画，建议沿用）。
