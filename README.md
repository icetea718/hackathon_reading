# hackathon_reading

一个面向 Windows 和 Android 的本地阅读器（Flutter），为后续的 AI 陪读、AI 翻译、划重点解读预留接口。当前为 **Phase 1：TXT / EPUB / PDF / 漫画 EPUB 阅读与书签**。

想一起开发？环境搭建、开发流程、代码约定和扩展指引见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 已实现（Phase 1）

- 书架：导入、展示、删除书籍，本地保存副本。
- 导入格式：TXT、EPUB、PDF，三种格式都可在应用内打开阅读。
- 重复导入保护：按文件内容计算 SHA-256，导入已在书架中的同一文件时提示「这本书已经在书架中」并跳过；旧版本导入的书在首次导入时自动补算哈希。
- TXT 编码自动识别：UTF-8（含 BOM）、UTF-16 LE/BE（含 BOM）、GB18030/GBK/GB2312；无法严格解码时按 UTF-8 容错处理。
- TXT 章节识别：基于行首标题规则（`第X章/节/卷/回/部/篇/集`、序章、楔子、前言、番外、`Chapter N` 等），无标题时整本书作为一章；`第X节` 出现在章之后时识别为二级小节，出现在任何章之前时按一级处理；误判控制：过长的行或句末带标点的行不会当作标题。
- EPUB 解析：支持 EPUB3 导航目录（nav）和 EPUB2 NCX 目录，嵌套目录会按片段锚点（`href#id`）把同一 XHTML 拆成多章，并保留章/节两级层级；按 spine 顺序提取正文纯文本并统一字符偏移；跳过导航页和纯封面页；损坏文件导入失败且不留下脏数据。目前只提取纯文本，不还原 CSS 样式和正文图片。
- 封面：导入 EPUB 时提取内嵌封面（EPUB3 `cover-image`、EPUB2 `meta name="cover"`、按文件名兜底），保存到本地目录并随书删除；已有旧书在启动后台补齐封面。没有封面或 TXT/PDF 书籍显示按格式配色的默认封面：书名用宋体排版在封面上，底部标注格式。
- 阅读器：TXT/EPUB 分页阅读——左右点击区、方向键和 PageUp/PageDown 翻页，中间区域点击用于选中文字；页脚显示「第 x / y 页 · 全书 X / Y 页」，全书总页数在后台逐章统计；目录抽屉跳章（二级小节缩进显示）、上一章/下一章、字号 14–28、行距 1.2–2.0、浅色/米色/深色背景；设置会保存，下次打开沿用。正文按章节懒加载，调整字号/行距或窗口大小后会停在包含原阅读位置的那一页。章节首行与标题一致时按层级加粗放大（章 1.5 倍、节 1.2 倍，随字号缩放），与正文明显区分。
- 书签：阅读页可给当前页添加/取消书签，同一章的不同页可以各有书签（双页阅读时按左页计算）；书签以全文字符偏移锚定，改字号或窗口大小后仍指向原来的文字，跳转落在包含该锚点的新页面。抽屉的“书签”栏列出全部书签，支持跳转和删除；跳到未加载章节里的书签也能准确定位。PDF 可按页添加/取消书签，抽屉“书签”栏列出页码并可跳转、删除。
- 高亮与笔记：TXT/EPUB 正文支持选中文字，弹出菜单可高亮（黄/绿/粉三色）或写笔记；高亮和笔记以全文字符偏移存储，改字号、改窗口大小后位置不变。顶部“标注”入口打开独立标注页，列出全部高亮和笔记（含章节名与笔记内容），可跳回原文或删除。
- 阅读进度：翻页后防抖保存（500ms），退出时保存；以“全书字符偏移”为锚点，重新打开同一本书会回到包含该位置的那一页。
- PDF 阅读：基于 pdfrx 渲染页面，支持缩放、上一页/下一页、输入页码跳转；读取 PDF 内嵌目录（书签）并在抽屉中展示，没有内嵌目录时按页跳转。PDF 进度以页码为锚点保存，重新打开回到原页。PDF 不写入章节表，不影响 TXT/EPUB 的章节目录。
- 漫画 EPUB：图片型 EPUB（固定版式）导入后按页横向滑读，支持目录跳页、左右方向键、上一页/下一页、页码进度；可按页添加/取消书签，在目录抽屉的“书签”栏跳转和删除；左栏可悬停唤出并固定。漫画暂不支持标注、陪读和阅读设置。
- AI 接入：设置页填写 OpenAI 兼容接口（Base URL、模型、API Key、温度、分段字数）并可测试连接；`OpenAiAssistantService` 以上述四个流式接口对接真实模型（SSE）。
- 翻译：TXT/EPUB 顶部「翻译本章」把整章译好后直接放进阅读页——单页模式替换当前页，双页模式左侧保留原文、右侧显示左页译文，译文模式下翻页一次走一页原文；再点一次「查看原文」回到原文。划词菜单的「翻译 / 从此段翻译」在弹窗中流式显示、可复制，弹窗最大宽度 560px，长译文不会被挤成窄条。已配置模型时走模型，未配置时自动回落到 MyMemory 免费接口（无需 Key）；长文按段落/句子切成 ≤500 字符分片，已经是中文的片段直接跳过。译完的文本按内容哈希写入本地 `translation_caches` 表，同一段再次翻译直接读缓存（标注「来自本地缓存」，另有「重新翻译」可强制刷新）。
- 书籍蒸馏：借鉴 [cangjie-skill](https://github.com/kangarooking/cangjie-skill) 的 RIA-TV++ 方法论，把 TXT/EPUB 按「分段提炼 → 分部合并 → 全书总览与语气 → 要点卡片」蒸馏成结构化底座并落库；任务可暂停、继续、取消，失败单元重试一次后停在暂停态，重跑复用已完成单元。
- 陪读对话：阅读页「陪读」按钮在宽窗口从右侧展开固定侧栏，正文相应收窄重排，可一边读一边提问；窄窗口回到底部面板。请求上下文 = 当前页位置与原文（本章第 X / Y 页、全书第 A / B 页；双页为左右两页）+ 全书蒸馏摘要 + 本章已读部分的摘录，可自由提问或一键总结本章。默认「不剧透」：发给模型的本章内容止于当前页开头，全书梗概、当前章与后续章节摘要、要点卡片都不会发送，系统提示也要求只依据当前页及之前作答；面板顶部有「允许剧透」开关，打开后才可讨论后面的情节。「总结本章」是明确操作，仍可覆盖整章。切章时侧栏自动跟随当前章；输入框回车直接发送，Shift+回车换行（中文输入法选词时的回车不算发送）；未配置模型时给出去设置的入口，但仍可浏览历史。对话按章节保存为多个线程，可在「历史」标签新建、重命名、删除；历史按章分组，当前章排在最前；打开旧章节的对话为只读，并可点「前往该章」跳转。助手只读取更早章节的对话纪要（≤400 字），不读取后续章节。PDF 暂不支持蒸馏（不写章节表）。
- 朗读陪伴（Windows）：参照 Coopanion 的 [GPT-SoVITS 语音世界插件](https://www.npmjs.com/package/@wocwang/cortico-world-gpt-sovits-for-coopanion) 实现了客户端那一半——设置页填写本机语音服务地址（默认 `http://127.0.0.1:8766`，即 chino-tts；也兼容 GPT-SoVITS `api_v2` 的 `http://127.0.0.1:9880`）、音色、语速、音量，助手每条回复气泡带「朗读」按钮，面板头部可「停止朗读」，也可打开「自动朗读回复」。文本先按标点切句：第一句单独成块尽快出声，其余短句合并到 150 字左右再请求（一条回复通常只有 2~3 次播放接缝，而不是每句一次），边合成边播放，并且始终保留两个请求在途，避免本机克隆引擎比实时慢时每句之间断气。播放走 `winmm.dll`（`dart:ffi`，不引入音频插件）：WAV 用 `PlaySoundW`，MP3 用 `mciSendStringW` 并轮询 `status … mode` 拿到真实结束点；播放前切掉引擎在每段首尾补的静音，音量通过改写 WAV 采样实现，句间只留 20ms。「启用朗读」开关只管自动朗读，手动点气泡上的喇叭一定会读。想用自己的声音：在 chino-tts 目录跑 `node add-voice.mjs --id 名字 --ref 录音.wav --text "录音里那句话"`（零样本克隆，不用训练）。

## 安装依赖

```bash
flutter pub get
```

PDF 渲染依赖 pdfrx，首次构建时由构建钩子从 GitHub 下载 PDFium 原生库。若 GitHub 不可达，构建会报 `build_hooks` 失败；可先用镜像下载对应平台的包，放到 `.dart_tool/hooks_runner/shared/pdfium_dart/build/chromium_8125/<平台>/`（Windows 为 `win-x64/pdfium.dll`）。本项目验证的是 `pdfium-win-x64.tgz`，来源为 `https://ghproxy.net/https://github.com/bblanchon/pdfium-binaries/releases/download/chromium%2F8125/pdfium-win-x64.tgz`。sqlite3 的原生库同理，缓存在 `.dart_tool/hooks_runner/shared/sqlite3/build/download-2bf39f2a/sqlite3.dll`，缺了也会报 `Building native assets failed`，从别的机器/检出目录拷一份即可跳过下载。

若无法开启开发者模式（`flutter pub get` 报 `Building with plugins requires symlink support`），可以先用目录联接代替符号链接，再带 `--no-pub` 构建：

```powershell
pwsh -File tool/plugin_symlinks.ps1
flutter build windows --debug --no-pub
```

`flutter pub get` 在失败前已经写好 `.dart_tool/package_config.json`，所以 `dart analyze`、`flutter test --no-pub` 照常可用。依赖变化后需要重新跑一次脚本。

只有修改了 Drift 表结构时才需要重新生成代码：

```bash
dart run build_runner build --delete-conflicting-outputs
```

Android 首次构建会下载 Gradle 与 Maven 依赖；若 `services.gradle.org` 超时，可手动把 `gradle-9.3.1-all.zip` 放入 `~/.gradle/wrapper/dists/gradle-9.3.1-all/<hash>/`，或把 `android/gradle/wrapper/gradle-wrapper.properties` 的 `distributionUrl` 指向可访问的镜像。

## 手动验收清单

Windows（`flutter run -d windows`）或 Android 真机/模拟器：

1. 导入一个 UTF-8 中文 TXT 和一个 GB18030 中文 TXT，正文与目录正常。
2. 导入一个 EPUB，章节顺序与目录正常，正文可读；带内嵌封面的 EPUB 在书架显示真实封面，无封面或 TXT/PDF 显示书名排版、按格式配色的默认封面。
3. 从目录跳到任意章节，上一章/下一章可用；左上角返回键能回到书架。
4. 给当前页添加书签，翻到同章另一页再加一个；两个书签都保留，在抽屉“书签”栏可分别跳转和删除；改字号后再从书签跳回，仍落在对应文字所在页。
5. 选中一段正文，用黄/绿/粉任一颜色高亮；再选一段写笔记；从顶部“标注”页跳回原文并删除其中一条。
6. 高亮后调整字号/行距或改变窗口大小，高亮仍在原文字上；翻到章节中部，关闭应用后重新打开同一本书，回到包含原段落的那一页。
7. 导入带内嵌目录的 PDF，打开后目录正确、点击目录能跳到对应页；翻到中间页退出重开，回到原页；缩放和输入页码跳转可用；在当前页添加书签，在抽屉“书签”栏跳转和删除。
8. 重复导入同一本书，出现「这本书已经在书架中」提示，书架不会多出一条。
9. 删除书籍后，书架条目和本地副本都消失。
10. 打开设置页，填写 Base URL、模型、API Key 后点「测试连接」应提示「连接成功」；故意填错 Key 应提示「连接失败：HTTP 401 …」。
11. 对一本 TXT 或 EPUB 打开「更多 → 蒸馏 → 开始蒸馏」，进度逐步推进、阶段文字随之变化；中途「暂停」再「继续」不重跑已完成片段；完成后四个标签（总览 / 章节地图 / 卡片 / 语气）都有内容。PDF 的蒸馏项应为灰色不可点。
12. 打开这本书，点顶部「陪读」：宽窗口应在右侧展开侧栏、正文收窄且仍可翻页阅读，点侧栏右上角关闭后恢复原排版；窄窗口为底部面板。问「这一章讲了什么」应有流式回答；问「这一页讲了什么」应围绕当前页作答；点「总结本章」只概括当前章；默认「不剧透」时问「后面会发生什么」，回答应拒绝透露后续内容；打开面板的「允许剧透」开关后再问，可以讨论后面的情节。
13. 导入一本图片型漫画 EPUB，打开后横向翻页（宽窗口默认左右双页，顶部按钮可切单页）、页码进度正常；顶部「目录」可跳页，「书签」可给当前页添加/取消书签，抽屉“书签”栏可跳转和删除；左栏悬停唤出后点「固定」可常驻；标注、陪读、设置保持灰色不可点。
14. 导入《你当像鸟飞往你的山》这类带嵌套目录的 EPUB，目录抽屉应显示“第一部分/第二部分…”和缩进的小节；跳到任意小节，正文首行标题明显大于正文；TXT 里 `第二章` 后出现的 `第一节` 同样显示为缩进小节。
15. TXT/EPUB 分页验收：左右点击区、方向键和 PageUp/PageDown 都能翻页，中间区域点击不翻页；翻过章节末页进入下一章首页；第一章首页的「上一页」和最后一章末页的「下一页」为禁用；空章节或短章节能正常显示；调整字号/行距/窗口大小后仍停在包含原段落的那一页；书签和标注跳转落在包含锚点的那一页；页脚「全书 X / Y 页」在后台统计完成后由「…」变为真实数字。
16. 朗读（Windows，需先在本机跑起 chino-tts 或 GPT-SoVITS `api_v2`）：设置页填写地址（默认 `http://127.0.0.1:8766`）与音色后点「测试语音」，应提示「语音服务可用：chino-tts…」并列出可用音色；地址末尾多写 `/v1` 或 `/audio/speech` 也能用。回到陪读面板，助手回复气泡右下角点喇叭开始朗读，播放期间图标变成声波，再点一次或点面板头部方块可停止；开启「自动朗读回复」后，每次回答完会自动念，且句与句之间不再长时间空白。
17. 双页阅读：阅读设置切换单页/双页（默认双页），TXT/EPUB 与漫画左右对照、按展开页翻页，窄窗口自动单页；PDF 仍为单页滚动。
18. 翻译：打开一本英文 TXT/EPUB，点顶部「翻译本章」应显示翻译进度，译完后单页模式当前页替换为译文、双页模式右侧显示左页译文；译文模式下翻页一次走一页原文，再点一次「查看原文」恢复原文。选中一段英文，在菜单点「翻译」只译选中内容，点「从此段翻译」译到本章末尾（弹窗显示，译文正常横向铺开而不是挤成窄条）。关闭后再选同一段点「翻译」，应标注「来自本地缓存」且不访问网络；点「重新翻译」可强制刷新。未配置模型时应自动使用 MyMemory 免费接口；断网时给出中文错误提示，阅读不受影响。

## 已知限制（Phase 1）

- PDF 只读取内嵌目录；没有内嵌目录的 PDF 只能按页码跳转，不做自动生成目录。
- PDF 暂无高亮、笔记和选区标注（按当前范围决定暂不实现）；PDF 右键菜单为 pdfrx 默认的英文文案。
- EPUB 只提取纯文本，不还原 CSS 和正文图片排版；嵌套目录需要指向片段锚点（`href#id`）才能拆出小节，目录里没有的 spine 页面会以文件名兜底成章。图片型 EPUB 按漫画模式打开，不做文字提取，也不支持高亮、笔记、陪读和阅读设置。
- 封面只取内嵌位图（不含 SVG）；无封面的书用书名排版占位，标题超过两行会省略。
- 扫描版 PDF 不做 OCR（后续按只读/占位处理）。
- TXT/EPUB 的高亮和笔记目前只能新增、查看、跳转和删除，暂不支持编辑内容或更换颜色。
- AI 相关：API Key 目前随设置明文保存在本地设置表，未接入系统凭据库；翻译已接入 UI，解读接口已实现但暂无 UI 入口；PDF 不支持蒸馏与陪读（不写章节表）。
- 阅读进度按字符偏移保存，用不同字号重新打开时会落在包含原字符位置的那一页，视觉位置可能相近但不完全相同。
- 朗读只做了 Windows：依赖 `winmm.dll`（WAV 走 `PlaySoundW`，MP3 走 MCI），Android 未接入；需要自己在本机跑语音服务（本项目不含 Python 运行时、模型下载和音色训练，这部分由 chino-tts / 原插件负责）；只有「停止」，没有暂停/续播；音量靠改写 WAV 采样实现，不是系统音量滑块。服务根路径 `/` 返回 404 是正常的——chino-tts 只提供 `/health`、`/voices` 和 `POST /audio/speech`，所谓「8766 打不开」指的是浏览器打开根路径；用「测试语音」按钮或 `curl http://127.0.0.1:8766/health` 验证。另外，`zhino-clone`（VoxCPM2 2B）在 CPU/低端 GPU 上比实时慢约 3 倍，句子再长也追不上，所以客户端做的是「首句尽快、其余合并、保持两路预取」，而不是把整段一次合成。
